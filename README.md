# GIFAA's website

## Sobre GIFAA

El Grupo de Investigación en Física y Aprendizaje Automático (cuyo acrónimo es GIFAA) es un grupo de investigación (no reconocido aún) dentro de la Universidad de Panamá. Está conformado por investigadores, docentes y estudiantes vinculados a la Universidad de Panamá. Su misión es ofrecer un espacio en el que sus miembros puedan colaborar con tal de desarrollar la intersección entre el machine learning y la física en Panamá.

## Sobre este repositorio

Este repositorio aloja las primeras versiones del sitio web estático del GI, que se sirve mediante GitHub Pages.

En primera instancia, el sitio es principalmente desarrollado mediante agentes y herramientas de IA (Google Antigravity, OpenCode, DeepSeek V4.1 Flash, Gemini, ...). ¿Por qué se hizo así? Porque se requería desplegar lo más rápido posible, con tal de ofrecer a los posibles interesados un medio para accesar rápidamente a la información relacionada con el GIFAA, que para entonces era una propuesta.

Lo ideal es que este sitio web sirva como ejercicio para sus colaboradores (que se espera sean en su mayoría miembros del GIFAA), por lo que debería escribirse a mano, sin ayuda de IA o por lo menos con bajo porcentaje de código escrito por IA. Es por esto también que se escogió hacerlo vanilla.

Por otro lado, el objetivo de este sitio web es servir toda la información necesaria sobre el GIFAA para el mundo sepa qué es, qué hace acualmente, hacia dónde se dirije y por qué es importante.
